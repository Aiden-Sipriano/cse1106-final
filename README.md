# Smart Study Room Occupancy Tracker
A program that tracks a study room's occupancy and displays a red LED when the room is full


## Requirements
* User can record when a person enters or leaves a study room<br>
* Maintain a current count of current occupants<br>
* Prevent occupancy from being negative<br>
* Prevent the count from exceeding the maximum room capacity<br>
* Display the current occupancy and room status<br>
* Save occupancy events to a file<br>
* Use an LED to indicate when the room is full<br>
* Support a change to the maximum room capacity<br>
